# SMPToolkit

All-in-one SMP plugin for **Paper 26.2**.

## Requirements

- Paper 26.2
- Java 25+
- LuckPerms recommended
- PlaceholderAPI optional

## Install

1. Put `SMPToolkit-0.2.jar` in `plugins/`.
2. Start the server.
3. Configure `plugins/SMPToolkit/config.yml` and `messages.yml`.
4. Restart or use `/smp reload` for reloadable settings.

## Build

```bash
mvn clean package
```

Output:

```text
target/SMPToolkit-0.2.jar
```

See `FEATURES.md` for the feature and command list.
